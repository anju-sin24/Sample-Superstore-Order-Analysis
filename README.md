# Sample-Superstore-Order-Analysis

 Project Overview:
This project presents an interactive **Sales and Order Analysis Dashboard** built using the Sample Superstore dataset. It provides insights into order trends, sales performance, profitability, shipping methods, regional distribution, and customer segments to support data-driven business decisions.

 Key Performance Indicators (KPIs):
- Total Orders: 5,009
- Total Sales: $2.30 Million
- Total Profit: $286.4K
- Profit Margin: 12.47%

 Dashboard Features:
- Monthly Order Trends: Visualizes changes in order volume over time to identify fluctuations and seasonal patterns.
- Shipping Mode Analysis: Compares order distribution across shipping methods and regions to understand shipping preferences.
- State-wise Order Analysis: Uses a geographical map to highlight order distribution across the United States.
- Customer Segment Analysis: Breaks down orders across Consumer, Corporate, and Home Office segments.
- Interactive Filters: Enables users to explore results by state and region for more focused analysis.

* Key Insights:
- The dashboard records approximately $2.30M in sales and $286.4K in total profit, with an overall profit margin of 12.47%.
- The Consumer segment leads with 2,586 orders, followed by Corporate with 1,514 and Home Office with 909.
- Standard Class has the highest order volume among the displayed shipping methods across all four regions.
- Order volumes fluctuate month to month, highlighting opportunities to investigate seasonal patterns and changes in demand.
- The state-level map reveals geographical differences in order distribution, helping identify major markets and areas for further analysis.

* Tools & Technologies:
- Tableau – Dashboard development and interactive visualizations
- Sample Superstore Dataset – Data source
- Data Analysis & Visualization – KPI tracking, trend analysis, geographical analysis, and customer segmentation

* Project Objective:
The objective of this project is to transform raw retail data into meaningful business insights through interactive visualizations, helping stakeholders evaluate performance, understand customer behavior, and identify opportunities for sales and operational improvement.

* Conclusion:
This dashboard demonstrates practical skills in business intelligence, data visualization, KPI development, and exploratory data analysis. It provides a consolidated view of Superstore performance and supports data-driven decision-making.
